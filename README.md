## 🚀 Learning Progress — AI / Ollama Development

Hands-on projects building local, privacy-first AI applications in C# and .NET using Ollama and Llama 3.2 — no cloud APIs, no Python.

✅ **Project 1: [LocalAIChat](https://github.com/erummirza/LocalAIChat)** — Basic AI chatbot. Single-turn prompts sent to a local LLM via Ollama's `/api/generate`, using HttpClient and System.Text.Json.

✅ **Project 2: [LocalAIChatMemory](https://github.com/erummirza/LocalAIChatMemory)** — AI with conversation memory. Maintains a `List<ChatMessage>` across turns and calls Ollama's `/api/chat` endpoint so the model retains context through a session.

✅ **Project 3: [AI Chatbot with Dependency Injection](https://github.com/erummirza/Chatbot-DI)** — Restructured the chatbot around an `IOllamaChatService` interface, with `HttpClient` provided via constructor injection instead of created manually — a proper Service Layer architecture.

✅ **Project 4: [RAG AI Application](https://github.com/erummirza/RAG-Document-QA)** — Retrieval-Augmented Generation. Reads a document, retrieves relevant context based on the user's question, and passes that context + question to Llama 3.2 to generate a grounded answer.

⏳ **Next:** Embeddings + vector search, RAG with Dependency Injection, and AI agents with tool/function calling.
